# Price before scope in a proposal

**In a client proposal the pricing table goes before the scope section, not after it.**

## What is known, and how

- `[MEASURED]` fewer scope disputes when price is stated first — win/loss review of 14 proposals,
  2026-04-20.
- `[REPORTED]` two clients said the price-last layout read as if the number were being hidden.

## Why it matters

Scope read before price is read as a wish list; scope read after price is read as what the price
buys. Same words, different document.

## What would change this

A framework agreement where price is fixed elsewhere and the proposal is scope only.
